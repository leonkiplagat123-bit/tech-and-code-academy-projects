# Project 12: M-Pesa Expense & Savings Tracker

A manual-entry personal finance dashboard using Kenyan shillings.

## Features
- Record income and expenses by category.
- Calculate income, expenses and current balance.
- Set a savings goal and view progress.
- Review transactions and clear local demo data.
- Responsive interface and localStorage persistence.

## Run
Open `index.html` in a modern browser.

## Learning goals
Form handling, numerical validation, array aggregation, date formatting, progress indicators and localStorage.

## Safety and limitations
This app does not connect to Safaricom, M-Pesa or any bank. All entries are manually typed and stored in this browser only. Never enter a PIN, password, account number or other sensitive financial information. Totals are for learning and should not be treated as financial records.
