# CI note

Project 10 is a Flask application, not a static site. Run its tests with:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

It cannot be published as a working Flask app using the existing Jirani Market GitHub Pages workflow; GitHub Pages serves static files only. Deploy the Flask backend to a Python-capable host when ready, and configure its database and environment secrets there.
