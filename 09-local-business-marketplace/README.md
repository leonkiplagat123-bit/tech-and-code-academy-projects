# Project 9: Jirani Market — Local Business Marketplace

A responsive local-business directory demo for discovering shops and services in Kenya.

## Features

- Search by business name, category, location, or description
- Filter by category and minimum customer rating
- Sort by featured, name, price, or rating
- Business profile dialog with description, location, typical price, and contact link
- Star ratings and customer review submission
- Save favourites and add a business listing
- WhatsApp contact links when a listing includes a phone number
- Responsive mobile, tablet, and desktop layouts
- Browser persistence for listings, favourites, and reviews using localStorage

## Tech stack

- HTML5, CSS3, and vanilla JavaScript
- Browser localStorage for demo data

## Run locally

1. Open or clone this repository.
2. Open 09-local-business-marketplace/index.html in a modern browser.
3. Try the search, category filter, minimum rating filter, and sorting options.
4. Select View details on a business card to read its profile and submit a demo review.
5. Save a favourite or add a listing to test browser persistence.

No build tools, API keys, or package installation are required.

## Important limitations

This is an educational frontend prototype. Sample businesses and seeded reviews are illustrative, not verified endorsements. Listings and reviews are stored only in the current browser and are not shared between visitors or devices. A production marketplace needs a backend database, authentication, server-side validation, spam protection, review moderation, privacy controls, and clear reporting/removal processes. Do not enter sensitive personal information.
