# Tech & Code Academy Projects

A beginner-friendly portfolio of eight practice projects:

1. Advanced Calculator — HTML, CSS, JavaScript
2. Task Management App — HTML, CSS, JavaScript
3. Student Management System — Python
4. Personal Budget Tracker — Python
5. Online Bookstore — HTML, CSS, JavaScript
6. Weather Forecast App — HTML, CSS, JavaScript (OpenWeather API key required)
7. Inventory Management System — Python
8. Online Learning Platform — HTML, CSS, JavaScript

Open each project folder and read its README for instructions. Python projects require Python 3.10+. The weather app requires your own OpenWeather API key; never commit real secrets.

These are educational starter projects, not production systems. License: MIT.
