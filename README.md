# Tech & Code Academy Projects

A learning portfolio of ten practical projects, from beginner exercises to intermediate web apps.

1. [Advanced Calculator](01-advanced-calculator/) — HTML, CSS, JavaScript
2. [Task Management App](02-task-management-app/) — HTML, CSS, JavaScript
3. [Student Management System](03-student-management-system/) — Python
4. [Personal Budget Tracker](04-personal-budget-tracker/) — Python
5. [Online Bookstore](05-online-bookstore/) — HTML, CSS, JavaScript
6. [Weather Forecast App](06-weather-forecast-app/) — HTML, CSS, JavaScript; requires your own OpenWeather API key
7. [Inventory Management System](07-inventory-management-system/) — Python
8. [Online Learning Platform](08-online-learning-platform/) — HTML, CSS, JavaScript
9. [Local Business Marketplace](09-local-business-marketplace/) — responsive HTML, CSS, JavaScript marketplace demo
10. [Jirani Delivery](10-jirani-delivery/) — Flask, SQLite, HTML, CSS, JavaScript food-ordering demo

## Running Project 9

Open `09-local-business-marketplace/index.html` in a modern browser. No build tools or API keys are required. Read that folder's README for features, implementation notes, and extension challenges.

## Running Project 10

Project 10 is a Flask application. From the repository root, run `cd 10-jirani-delivery`, create and activate a Python virtual environment, install `requirements.txt`, then run `python app.py`. Open http://127.0.0.1:5000. See [the Project 10 README](10-jirani-delivery/README.md) for Windows/macOS/Linux setup and automated tests.

Projects are educational examples, not production-ready services. Project 9 uses browser local storage: listings and favorites are saved only in the current browser and are not shared with other users. Project 10 uses a local SQLite database and does not process real payments or deliveries. Never commit passwords, API keys, or other secrets.

Python projects require Python 3.10+. See each project folder for specific instructions.
