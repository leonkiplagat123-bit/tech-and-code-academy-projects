# Project 11: Smart School Management System

A responsive browser-based prototype for a simple student register.

## Features
- Add student name, class, attendance and grade.
- Dashboard counts total students, present students and average grade.
- Remove student records.
- Browser localStorage persistence and mobile layout.

## Run
Open `index.html` in a modern browser. No server or API key is required.

## Learning goals
DOM events, forms, validation, arrays, rendering tables, localStorage and responsive CSS.

## Limitations
This is a learning demo, not a school information system. Data stays in one browser and is not backed up or shared. Do not enter real student records or sensitive personal information. A production system needs authentication, role-based access, secure storage, backups and privacy safeguards.
